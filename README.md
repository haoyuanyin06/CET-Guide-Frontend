# CET-Guide-Frontend

This project is a pure front-end lightweight tool for preparing for CET-4 and CET-6 exams. It is quickly built using AI Coding and only has a front-end web interface. It can be opened locally and used directly.
It summarizes all the complete preparation materials for university English CET-4 and CET-6, getting rid of scattered notes. It centrally organizes the complete solution methods for listening, reading, translation, and writing, and arranges frequently used and easily confused words, as well as typical and error-prone traps. It is suitable for quick review and consolidation before the exam.
